# Rekomendowana sesja — 15–20 minut

To prawdziwa kariera, bez osobnej symulacji demonstracyjnej, wstrzykniętych wyników lub wymuszonych ofert. Czas jest planem dla człowieka, nie zmierzonym wynikiem automatyzacji.

| Czas | Co zrobić | Co pokazuje gra |
|---|---|---|
| 0–1 min | Start; krótko otwórz O projekcie / Publisher Info | Obietnica kariery, core loop, Pre-Alpha, zakres projektu |
| 1–4 min | NOWA KARIERA; cztery etapy kreatora | Człowiek, doświadczenie, licencja, profil; pojedyncze pytania; szkic |
| 4–6 min | Wybierz dostępny klub, dokładnie dwa cele; przeczytaj powitanie | Środowisko pracy, prezes, prawdziwy cel zarządu i osobne cele trenera |
| 6–8 min | Drużyna: obejrzyj XI, kondycję i zawodników poza XI; wybierz plan | Sztab dobiera ludzi automatycznie, plan ma koszt i konsekwencje |
| 8–10 min | Trening: przeczytaj diagnozę i dwa warianty; wykonaj jeden mikrocykl | Rzeczywisty kompromis kondycja/gotowość; wynik wraca na Pulpit |
| 10–11 min | Pulpit → Rywal; przeczytaj OVR i dostępne wyniki; Do meczu | Dane istniejącego świata, bez wymyślania stylu przeciwnika |
| 11–15 min | Następne 15 minut; reaguj na zatrzymania; zmień pressing lub mentalność | Koszt fizyczny pressingu; obustronne ryzyko mentalności; decyzje z ławki |
| 15–17 min | Raport, Pulpit, dostępne sprawy | Wynik, kondycja i konsekwencje; cele wymagają sezonu, nie jednej kolejki |
| 17–20 min | Kariera / licencje / Rynek pracy; Zapisz; menu; KONTYNUUJ | Warsztat, reputacja, przyszła praca, prawdziwy wielosezonowy horyzont i wznowienie |

Opcjonalnie przed karierą włącz lokalny pomiar w Publisher Info. Po sesji sam eksportuj raport; nie jest wysyłany automatycznie. Nie używaj prawdziwych danych osobowych trenera w sesji pokazowej.

Na debiut polecana jest Klasa B, dowolny dostępny klub z najbliższym spotkaniem. W auditowanej sesji: Śląskie / Rybnik I / Górnik II Radlin; dwa treningi i pierwszy rywal Płomień II Ochojec. Klub nie jest blokowany ani narzucony.

Nie oczekuj formalnych ofert latem już po pierwszym meczu. Rynek wyjaśnia warunki i rozróżnia zimową obserwację oraz ofertę letnią; pusty rynek na początku kariery jest poprawnym stanem. Nie rozgrywaj całego sezonu tylko po to, żeby pokazać licencję, ofertę lub nagrodę.

Zapis należy do konkretnej domeny i przeglądarki. Przed zmianą adresu/urządzenia użyj eksportu w ustawieniach; nowy Deploy Preview nie przejmie automatycznie zapisu produkcji.
