# Niezależny test człowieka — 15–20min

Organizator przekazuje tylko link do właściwego buildu oraz hasło dostępu, jeśli potrzebne; nie tłumaczy zasad i nie prowadzi przez ekrany. Jeśli link wymaga konta Netlify/GitHub, test dostępu niezaliczony — nie prosić o konto developerskie.

Tester gra15–20min, nie czyta instrukcji autora. Zapisuje nazwy ekranów i momenty, w których nie rozumie informacji, nie wie co dalej lub utknął. Używa pseudonimu. Opcjonalnie przed grą włącza lokalny pomiar w Publisher Info; po sesji pobiera „Eksportuj anonimowy raport” i dobrowolnie dołącza JSON do odpowiedzi organizatorowi. Nic nie wysyła się automatycznie; brak eksportu nie unieważnia testu.

Po sesji:
1. O czym jest TEN TRENER, własnymi słowami?
2. Czy w pierwszej minucie wiedziałeś, gdzie zacząć i co zrobić?
3. Gdzie nie wiedziałeś, co zrobić dalej?
4. Która decyzja była najciekawsza i dlaczego?
5. Czy zauważyłeś konsekwencję swojej decyzji? Jaką?
6. Co było niezrozumiałe lub wyglądało na niedokończone?
7. Czy chciałbyś kontynuować karierę przez kolejne sezony? Dlaczego?
8. Kojarzysz grę bardziej z karierą trenera czy zarządzaniem całym klubem?

Organizator zapisuje także czas, problemy urządzenia i dostępu. Nie odpowiada za testera. Test pozostaje do wykonania przez człowieka; audyt agenta nie jest niezależnym badaniem.
